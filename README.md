# Ruchitha Associates Website

This is the source code for the Ruchitha Associates website, built with Next.js and Tailwind CSS.

## 📝 Editing Content
To add, edit, or remove Jobs, Courses, or News, please check the instructions in `content/README.md`.

## 🚀 Running Locally
To run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
